# Brouillons (non publiés)

Scripts de créatures qui n'ont pas passé la relecture des planches en 3 essais (fiche §5.5) : `vox:build` ne les lit pas,
le jeu garde le modèle construit par le code. Planches des essais : `docs/captures/bestiaire/lot4/` (Mycélin, Amanitox).

- `_polypore.ts`, `mycelin.ts`, `amanitox.ts` : lignée Mycélin → Amanitox, « porteur de polypores » (lot 4). Le corps
  se lit comme un bloc et la tête pas assez ; à reprendre avec un autre plan de corps (voir le rapport du lot 4).
